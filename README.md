# MakoMaster

基于 Dalamud 的《最终幻想14》国服“魔光键影”辅助插件，当前为测试版，使用 API 15。

## 使用方法

1. 在卫月开发插件中添加 `MakoMaster.dll`，加载后输入 `/makomaster` 打开控制窗口。
2. 点击“开始”自动输入，点击“停止”结束。只在游戏窗口处于前台时操作。
3. 循环游玩：选中入场 NPC，勾选“循环开局”，在右侧填写次数，再点击“开始”。每局自动退出结算，完成指定次数后停止。不会自动移动。
4. 随机间隔在默认折叠的“高级设置”中调整；默认每键 30～80 毫秒、每词 500～1200 毫秒。已有设置会保留。

## 输入规则

- 优先级：绿色护盾 → 当前可打断读条 → 当前不可打断读条 → 普通词；同级优先离画面下方中央更近的词。正在输入的词保持锁定。
- 读取完整词后忽略标点匹配词库；候选提前出现就直接选。整词最多翻下一页，仍找不到就记录并逐字输入。
- 发送后不检查成功，不重试当前题目；清空残留后处理下一词。目标消失、换词或进入下一关后可重新识别新题目。
- “运动体探知干扰器”和“诅咒视线”在预计读条结束前后各 0.5 秒暂停按键。结束时间由实际读条填充速度估算，受帧率和 UI 更新影响；不再暂停整个读条。缺少可用进度时不能保证提前半秒，只保留读条消失后的半秒暂停。
- 自动记录遇到的词、缺词与已确认的拼音组合，不覆盖原有词条。包含 `ü` 的输入反馈与按键 `v` 兼容。

## 数据与日志

词库、设置和 `captures/` 位于 DLL 同目录。测试阶段持续保存日志，约 64 MiB 自动分卷。
`captures/`、个人学习词库、运行设置及构建缓存均已通过 `.gitignore` 排除，不上传仓库。
更新前请停止并卸载旧版 MakoProbe，再加载 MakoMaster；不要同时启用两个插件。可将旧目录中的词库和设置复制到新 DLL 目录，旧日志继续保留。

## 本地构建

需要 .NET 10 SDK 和本机卫月 API 15 的依赖 DLL：

```powershell
dotnet build .\MakoMaster.csproj -c Release -p:DalamudLibPath="你的卫月 Hooks 版本目录"
```

输出位于 `bin/Release/net10.0-windows/`。仓库不包含卫月 DLL。

本项目仍需实机验证循环菜单、输入法翻页及读条边界；模拟检查通过不代表所有游戏场景均已确认。

行为检查：`dotnet run --project .\tests\BehaviorTests\BehaviorTests.csproj`。
