# MakoMaster

魔光键影自动输入、循环游玩与宝箱开启插件，适用于《最终幻想14》国服。

[English](README.en.md)

## 安装

在卫月设置的“自定义插件仓库”中添加以下地址，保存后刷新插件列表，搜索 **MakoMaster** 安装：

```text
https://raw.githubusercontent.com/DocherPap/MakoMaster/main/repo.json
```

自动传送需要启用 **Lifestream**，自动寻路需要启用 **vnavmesh**。

## 使用方法

输入 `/makomaster` 打开窗口，在四个模式前的单选框中选择一个，再点击“开始”。点击“停止”可随时结束操作并解除输入框焦点维护。窗口默认贴合内容大小，展开或收起高级设置时会重新适配，也可手动拖动、调整大小；标题栏叉号仅关闭窗口，正在运行的操作会继续。再次输入 `/makomaster` 可重新打开。

| 模式 | 切换模式时的间隔预设 | 操作 |
| --- | --- | --- |
| 单人排本 | 默认 | 自动选择 NPC、报名、确认进本、打字、退出结算，完成旁边填写的局数后停止。 |
| 组队队长 | 快速 | 需要 4 人小队且自己是队长，自动报名、确认进本、打字、退出结算，完成指定局数后停止。 |
| 组队队员 | 快速 | 需要 4 人小队且自己不是队长，等待队长报名，自动确认进本、打字、退出结算，直到手动停止。 |
| 开启宝箱 | 不适用 | 开启旁边填写数量的宝箱，宝箱不足时开到用完。 |

- 排本次数可填 **0～9999**；**0** 表示一直运行到手动停止。宝箱数量 **0** 表示一直开到普通背包中的宝箱用完。
- 组队模式支持普通小队和跨服小队；人数或队长身份不符时无法启动，运行中返回入场区发现不符时等待恢复。
- 每次结算算一局，关卡不单独计数。已在局内时点击开始会接续当前游戏。
- 单人排本和组队队长模式会自动传送至金碟游乐场，与魔光键影向导对话进入键斗广场，再寻路至报名登记员。NPC 已加载时使用实时世界坐标。切换模式或修改数量前请先停止。

## 前往广场与兑换

- 点击“前往报名npc”或“前往兑换npc”，会传送、进入广场并走到对应 NPC 的侧边停靠点，抵达后停止，不自动报名或兑换。
- 展开“高级设置”，在按键随机间隔上方勾选“在自动排本时超过 … 点数后自动兑换宝箱”。只有人物位于键斗广场时才能启用，鼠标悬停可查看提示。默认阈值为 **9100**；仅在自动排本期间，持有金碟点严格大于阈值时前往兑换员，在“其他”分类兑换魔光键影宝箱。
- 阈值是触发条件。开始兑换后会尽量用完可用金碟点，受背包容量限制；兑换后返回报名登记员，正在排本时继续原流程。
- 点击“停止”会取消本插件发起的传送／寻路、停止兑换，并关闭自动兑换。缺少依赖、寻路失败或兑换结果无法确认时会显示原因，请停止后重试。

## 高级设置

展开“高级设置”可调整随机间隔，修改前先停止自动打字。

| 间隔 | 默认 | 预设：快速 | 预设：迪迦 |
| --- | --- | --- | --- |
| 每次按键 | 40～100 毫秒 | 20～50 毫秒 | 10 毫秒 |
| 每个词 | 800～1600 毫秒 | 400～800 毫秒 | 0 毫秒 |

点击“预设：默认”、“预设：快速”或“预设：迪迦”应用；迪迦使用允许的最短间隔，仍等待输入法响应并避让危险技能。点击“保存设置”可保留参数供下次使用。

高级设置末尾的“依赖插件”显示当前状态：红色“未安装”、黄色“未启用”、绿色“已启用”。缺少或未启用依赖时，导航按钮和自动兑换会禁用，悬停可查看原因。单人排本和组队队长仍可开始：已在报名 NPC 交互范围内时照常报名，否则等待手动前往键斗广场；运行中依赖被停用时会暂停相关操作，恢复后继续。寻路需要 vnavmesh；不在金碟游乐场或键斗广场时，自动前往还需要 Lifestream。队员模式、局内打字和开宝箱不受这些依赖限制。TextAdvance 和 YesAlready 不属于当前运行依赖，无需额外安装。

“聊天框输出”默认开启；取消勾选后，插件不再向聊天框输出提示或错误消息。

“保存日志”默认关闭，每次重新加载都会恢复关闭。需要保留日志及新增学习词条时勾选“保存日志”，取消勾选后结束保存；关闭时新增词条仅在本次加载期间有效。

## 使用时注意

- 保持游戏窗口在前台；切出游戏会暂停操作，返回后继续。自动对话使用内部控件接口，不移动或点击鼠标；普通对话会自动推进，确认框仅处理当前流程的提问。
- 安装并启用中文输入法，建议安装词库。插件会尝试切换，失败或无法确认状态时请按窗口提示手动切换。
- 关闭 CapsLock，松开 Shift、Ctrl、Alt、Win 等修饰键。
- 自动打字期间会持续恢复小游戏输入框焦点，需要操作其他输入框时先点“停止”。
- 特定技能期间会自动停字，等待自动恢复即可。
