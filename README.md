# MakoMaster

适用于《最终幻想14》国服魔光键影的自动输入、循环排本与宝箱工具。

[English](README.en.md)

## 安装

在卫月设置的“自定义插件仓库”中添加以下地址，保存并刷新插件列表，搜索 **MakoMaster** 安装：

```text
https://raw.githubusercontent.com/DocherPap/MakoMaster/main/repo.json
```

## 开始使用

1. 输入 `/makomaster` 打开窗口。
2. 选择模式，填写次数或数量，点击“开始”。
3. 点击“停止”可结束当前操作，包括自动输入、传送、寻路和兑换。

| 模式 | 使用方法 | 默认间隔 |
| --- | --- | --- |
| 单人排本 | 自动报名、确认进本、输入和退出结算，完成指定局数后停止。 | 默认 |
| 组队队长 | 需要 4 人小队且自己是队长，自动报名并完成指定局数。 | 快速 |
| 组队队员 | 需要 4 人小队且自己不是队长，等待队长开局，自动确认、输入和退出结算，直到手动停止。 | 快速 |
| 开启宝箱 | 开启指定数量的魔光键影宝箱，背包中宝箱不足时提前结束。 | — |

- 排本次数为 **0～9999**，**0 代表不限制次数**；宝箱数量为 **0** 时开到普通背包中没有该宝箱。
- 一次完整结算算一局，关卡不单独计数；局内启动会接续当前游戏。
- 组队模式支持跨服小队。人数或队长身份不符时无法启动；运行中返回广场发现不符时等待恢复。
- 切换模式或修改次数前先停止。切换模式会应用该模式的间隔预设。

标题栏叉号只关闭窗口，**不会停止正在运行的操作**；再次输入 `/makomaster` 可打开。窗口可拖动、调整大小，展开或收起高级设置时会自动适配内容。

## 传送与寻路

| 插件 | 提供的功能 |
| --- | --- |
| Lifestream | 从其他区域传送至金碟游乐场 |
| vnavmesh | 自动寻路至向导、报名 NPC 和兑换 NPC |

依赖可用时，单人排本和组队队长模式会自动前往金碟游乐场，与向导对话进入键斗广场，再到报名处开始游戏。

没有安装或启用依赖也可以使用单人、队长模式：**手动前往键斗广场，在报名 NPC 可交互的位置点击“开始”即可**。不在交互范围内时，插件会等待并提示手动前往。

- **前往报名npc**：走到报名处的侧边停靠点，不自动报名。
- **前往兑换npc**：走到兑换处的侧边停靠点，不自动兑换。

两个导航按钮会在缺少所需依赖时禁用。高级设置末尾以红色“未安装”、黄色“未启用”、绿色“已启用”显示状态。依赖恢复后可继续相关操作。局内输入、队员模式和开启已有宝箱无需这些插件；**TextAdvance、YesAlready 也不是必需依赖**。

## 自动兑换宝箱

在键斗广场展开“高级设置”，勾选“在自动排本时超过 … 点数后自动兑换宝箱”，填写触发点数，默认 **9100**。此功能需要启用 vnavmesh；悬停该设置可查看提示。

仅在自动排本期间，持有的魔光键影金碟点**超过**阈值时，插件才会前往兑换员，在“其他”分类兑换宝箱，随后返回报名处继续。

**阈值只决定何时触发，不会保留该数量点数。** 触发后会尽量把可用点数全部兑换为宝箱，直到点数不足或背包空间不足。点击“停止”也会关闭自动兑换。

## 高级设置

停止后可修改按键和每词间隔，或选择预设：

| 间隔 | 预设：默认 | 预设：快速 | 预设：迪迦 |
| --- | --- | --- | --- |
| 每次按键 | 40～100 毫秒 | 20～50 毫秒 | 10 毫秒 |
| 每个词 | 800～1600 毫秒 | 400～800 毫秒 | 0 毫秒 |

预设应用后在启动时生效；需要保存参数时点击“保存设置”。迪迦仍会等待输入法响应，并保留危险技能的暂停。

- **聊天框输出**：默认开启，关闭后不再向聊天框输出插件提示或错误消息。
- **保存日志**：默认关闭，重新加载后恢复关闭。勾选后保存日志和新增学习词条；关闭时新词仅在本次加载期间有效。遇到问题时可先开启，再复现问题。

## 使用时注意

- 保持游戏在前台；切出后暂停，返回后继续。
- 安装并启用中文输入法。插件会尝试切换，无法确认时请按窗口提示手动处理。
- 关闭 CapsLock，松开 Shift、Ctrl、Alt、Win 等修饰键。
- 自动输入期间会维护小游戏输入框焦点，操作其他输入框前请先停止。
- 对话会自动推进，不操控鼠标；危险技能期间会短暂停字，等待恢复即可。
- 寻路失败或兑换结果无法确认时，查看窗口提示，停止后再重试。
