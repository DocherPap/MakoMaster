# MakoMaster

魔光键影自动输入、循环游玩与宝箱开启插件，适用于《最终幻想14》国服。

[English](README.en.md)

## 安装

在卫月设置的“自定义插件仓库”中添加以下地址，保存后刷新插件列表，搜索 **MakoMaster** 安装：

```text
https://raw.githubusercontent.com/DocherPap/MakoMaster/main/repo.json
```

## 开始与停止

1. 输入 `/makomaster` 打开控制窗口。
2. 靠近魔光键影入场 NPC，或在已开始的小游戏中，点击“开始”。
3. 点击“开始”后持续运行：自动报名、打字、退出结算，再开始下一局；已在局内则直接接续当前游戏，直到手动停止。
4. 点击“停止”结束操作并解除输入框焦点维护。

## 循环游玩

勾选“循环开局”可启用 4 人小队判断（支持跨服小队）：队长自动选中入场 NPC 并报名；队员等待队长开局，并自动确认出发。进入游戏后都会自动打字、退出结算，再继续下一局，直到点击“停止”。非 4 人小队时关闭小队循环判断，按普通“开始”持续运行。

每次结算算一局，关卡不单独计数。NPC 太远时请自行走近，插件不会自动移动。

## 开启宝箱

先停止自动打字或循环，再在“魔光键影宝箱”的数量框中填写：

- **大于 0**：开启指定数量，宝箱不足时开到用完。
- **0**：一直开到普通背包中没有该宝箱。

点击“开始开箱”执行；点击“停止开箱”或总“停止”按钮结束。

## 高级设置

展开“高级设置”可调整随机间隔，修改前先停止自动打字。

| 间隔 | 默认 | 预设：快速 | 预设：迪迦 |
| --- | --- | --- | --- |
| 每次按键 | 40～100 毫秒 | 20～50 毫秒 | 10 毫秒 |
| 每个词 | 800～1600 毫秒 | 400～800 毫秒 | 0 毫秒 |

点击“恢复默认间隔”、“预设：快速”或“预设：迪迦”应用；迪迦使用允许的最短间隔，仍等待输入法响应并避让危险技能。点击“保存设置”可保留参数供下次使用。

“保存日志”默认关闭，每次重新加载都会恢复关闭。需要保留日志及新增学习词条时点击开启，再点“关闭日志”结束保存；关闭时新增词条仅在本次加载期间有效。

## 使用时注意

- 保持游戏窗口在前台；切出游戏会暂停操作，返回后继续。
- 安装并启用中文输入法，建议安装词库。插件会尝试切换，失败或无法确认状态时请按窗口提示手动切换。
- 关闭 CapsLock，松开 Shift、Ctrl、Alt、Win 等修饰键。
- 自动打字期间会持续恢复小游戏输入框焦点，需要操作其他输入框时先点“停止”。
- 特定技能期间会自动停字，等待自动恢复即可。
